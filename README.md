# WAVPlayer

##  專案簡介

本播放器除了具備基本的播放、暫停與停止功能外，也透過呼叫 Windows 內建的 `winmm.dll`，使用 MCI（Media Control Interface）實作音訊控制功能。

透過 MCI，本專案能夠取得 WAV 檔案長度、控制播放位置、實作進度條拖曳跳轉，以及支援循環播放功能，讓使用者能更直覺地控制音訊播放進度。

## 主要功能

### 1. 檔案瀏覽

使用者可以透過 `OpenFileDialog` 選取本地端的 `.wav` 音訊檔案，並將檔案路徑顯示於文字方塊中。

### 2. 播放控制

- **播放 / 暫停**
  - 按下播放按鈕後開始播放 WAV 音訊。
  - 播放中再次按下可暫停音訊。
  - 暫停後可從原本位置繼續播放。

- **停止**
  - 停止目前音訊播放。
  - 將播放位置重置為開頭。
  - 同時更新進度條與時間顯示。

### 3. 進度控制

- **進度條顯示**
  - 播放時會即時更新目前播放進度。
  - 讓使用者清楚知道音訊目前播放到哪個位置。

- **拖曳跳轉**
  - 使用者可以拖曳進度條，或點擊進度條上的指定位置。
  - 音訊會立即跳轉到對應的播放時間。

- **時間顯示**
  - 以 `mm:ss` 格式顯示播放時間。
  - 顯示格式如下：

```text
目前時間 / 總時長
00:15 / 03:20

### 4.支援循環播放功能
當使用者開啟重複播放後，音訊播放結束時會自動回到開頭並再次播放，直到使用者按下停止或關閉循環播放。
