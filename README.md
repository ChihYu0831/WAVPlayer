# WAVPlayer

這是一個基於 C# Windows Forms 開發的簡易 WAV 音效播放器。本專案為「視窗程式設計 (II)」課程之上課練習作品，旨在練習多媒體 API 的呼叫、介面設計以及播放邏輯控制。

📋 專案簡介
本播放器除了具備基本的播放、暫停與停止功能外，亦透過調用 Windows winmm.dll (MCI) 實作了進度條拖曳跳轉以及循環播放功能，讓使用者能更靈活地控制音訊播放進度。

✨ 主要功能
檔案瀏覽：透過 OpenFileDialog 選取本地端的 .wav 檔案。

播放控制：

播放/暫停：切換播放狀態。

停止：停止播放並重置進度。

進度控制：

進度條顯示：實時顯示當前播放位置。

拖曳跳轉：點擊或拖曳進度條可即時跳轉至特定時間點。

時間顯示：以 mm:ss 格式顯示「目前時間 / 總時長」。

循環播放：支援自動重複播放功能。
